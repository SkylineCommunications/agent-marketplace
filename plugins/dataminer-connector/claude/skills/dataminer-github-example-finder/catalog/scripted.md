Description:
Examples of Scripted Connectors — Python or PowerShell scripts that push JSON data via a local HTTP call to the DataMiner Data API, which auto-generates an element from a matching connector. Part of the Data Sources/DataAPI feature.

Why Use It:
Reference for the Scripted Connector pattern: script structure, JSON payload format, and how to register a data source. Note: this feature was not yet generally available at the time of the last README update — verify availability in your DataMiner version.

Typical Use Cases:
- Pulling data from any source (cloud APIs, files, scripts) into DataMiner without writing a full XML connector
- Rapid prototyping of data ingestion via Python or PowerShell
